# 🎬 Studio Gear — מערכת השאלת ציוד

מערכת לניהול ציוד סטודיו — מעקב אחר השאלות, סריקת ברקודים, והתראות על איחורים.

---

## 🗂 מבנה הפרויקט

```
השאלת ציוד/
├── backend/          # Node.js + Express + SQLite
│   └── index.js      # שרת ה-API
├── frontend/         # Angular 21
│   └── src/app/
│       ├── pages/
│       │   ├── equipment-list/   # רשימת ציוד (תצוגת קטגוריות)
│       │   ├── equipment-detail/ # פרטי פריט + השאלה
│       │   ├── equipment-form/   # הוספה/עריכה
│       │   ├── categories/       # ניהול קטגוריות
│       │   ├── scan/             # סריקת ברקוד
│       │   ├── loans/            # ניהול השאלות
│       │   ├── approvals/        # הפקת אישורים לתלמידות
│       │   └── admin/            # ניהול המערכת ונתוני תלמידות
│       ├── services/
│       │   └── api.service.ts    # תקשורת עם ה-backend
│       └── models.ts             # טיפוסי TypeScript
└── package.json      # סקריפטים להרצה
```

## 🚀 הרצת הפרויקט

### דרישות מקדימות
- Node.js v18+
- npm

### התקנה (פעם ראשונה בלבד)
```bash
# התקנת תלויות backend
cd backend
npm install

# התקנת תלויות frontend
cd ../frontend
npm install
```

### הרצה
פתח **שני טרמינלים**:

**יצירת חשבון מנהלת ראשוני (פעם אחת):**
```bash
cd backend
npm run create-admin
```
הפקודה תבקש שם, אימייל וסיסמה (לפחות 12 תווים). הקלדת הסיסמה מוסתרת. אין חשבון ברירת מחדל או הרשמה ציבורית.

**טרמינל 1 — Backend:**
```bash
cd backend
node index.js
# רץ על http://localhost:3000
```

**טרמינל 2 — Frontend:**
```bash
cd frontend
ng serve
# רץ על http://localhost:4200
```

### משתמשות והרשאות

יש להתחבר עם אימייל וסיסמה. מנהלת מערכת יוצרת חשבונות נוספים במסך **ניהול מערכת**:

| תפקיד | הרשאות |
|-------|---------|
| מנהלת מערכת | גישה מלאה, כולל יצירה, השבתה ושינוי תפקידים של חשבונות |
| לבורנטית | גישה מלאה למערכת, ללא ניהול חשבונות והרשאות |
| מזכירות | צפייה בכל המערכת; עדכון נתוני סטודנטיות, ייבוא נתוני סטודנטיות וניהול אישורים |

בדיקות ההרשאה מתבצעות בשרת, והתחברות נשמרת בעוגיית session מסוג HttpOnly. סיסמאות נשמרות כ-hash עם salt ולא כטקסט רגיל.
בפריסה עם דומיין יש להגדיר `APP_ORIGIN` לכתובת האתר המלאה ולהפעיל `NODE_ENV=production` כדי שעוגיית ההתחברות תסומן `Secure`.

|-------|-----|--------|
| id | INTEGER | מזהה ייחודי |

| card_last4 | TEXT | 4 ספרות אחרונות של כרטיס האשראי |
| card_expiry | TEXT | תוקף הכרטיס |
| card_holder | TEXT | שם בעל הכרטיס |
| payment_status | TEXT | סטטוס תשלום: `pending` / `charged` / `none` |

| phone | TEXT | טלפון |
| track | TEXT | מסלול לימודים |

### טבלת `approval_types`
| עמודה | סוג | תיאור |
|-------|-----|--------|
| id | INTEGER | מזהה סוג האישור |
| name | TEXT | שם האישור |
| template | TEXT | נוסח האישור, כולל משתנים להחלפה |
| signature | TEXT | סוג החתימה |

### הודעות ומשימות אישיות
הטבלאות `messages` ו-`message_reactions` שומרות הודעות פרטיות ותגובות אימוג׳י.
הטבלה `personal_tasks` מקשרת הודעה למשימה של המשתמשת שהוסיפה אותה, עם תאריך יעד ומצב ביצוע.
כל משתמשת רואה ומשנה רק את ההודעות והמשימות שבהן היא משתתפת או שהיא יצרה.
