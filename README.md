# 🎬 Studio Gear — מערכת השאלת ציוד

מערכת לניהול ציוד סטודיו — מעקב אחר השאלות, סריקת ברקודים, והתראות על איחורים.

---

## 🗂 מבנה הפרויקט

```
השאלת ציוד/
├── backend/          # Node.js + Express + SQLite
│   └── index.js      # שרת ה-API
├── frontend/         # Angular 21
│   └── src/app/
│       ├── pages/
│       │   ├── equipment-list/   # רשימת ציוד (תצוגת קטגוריות)
│       │   ├── equipment-detail/ # פרטי פריט + השאלה
│       │   ├── equipment-form/   # הוספה/עריכה
│       │   ├── categories/       # ניהול קטגוריות
│       │   ├── scan/             # סריקת ברקוד
│       │   └── loans/            # ניהול השאלות
│       ├── services/
│       │   └── api.service.ts    # תקשורת עם ה-backend
│       └── models.ts             # טיפוסי TypeScript
└── package.json      # סקריפטים להרצה
```

---

## 🚀 הרצת הפרויקט

### דרישות מקדימות
- Node.js v18+
- npm

### התקנה (פעם ראשונה בלבד)
```bash
# התקנת תלויות backend
cd backend
npm install

# התקנת תלויות frontend
cd ../frontend
npm install
```

### הרצה
פתח **שני טרמינלים**:

**טרמינל 1 — Backend:**
```bash
cd backend
node index.js
# רץ על http://localhost:3000
```

**טרמינל 2 — Frontend:**
```bash
cd frontend
ng serve
# רץ על http://localhost:4200
```

## 📱 מסכים

| מסך | נתיב | תיאור |
|-----|------|--------|
| ציוד — קטגוריות | `/equipment` | תצוגת קטגוריות עם ספירה וסטטוס |
| ציוד — רשימה | `/equipment?cat=...` | רשימת פריטים בתוך קטגוריה |
| פרטי פריט | `/equipment/:id` | פרטים, השאלה/החזרה, היסטוריה |
| הוספת ציוד | `/equipment/new` | טופס הוספת פריט חדש |
| עריכת ציוד | `/equipment/:id/edit` | עריכת פרטי פריט |
| קטגוריות | `/categories` | הוספה ומחיקה של קטגוריות |
| סריקה | `/scan` | סריקת ברקוד (מצלמה או הקלדה) |
| השאלות | `/loans` | כל ההשאלות עם פילטרים |

## 🗄 מסד הנתונים

### טבלת `equipment`
| עמודה | סוג | תיאור |
|-------|-----|--------|
| id | INTEGER | מזהה ייחודי |
| barcode | TEXT | ברקוד (ייחודי) |
| name | TEXT | שם הציוד |
| category | TEXT | קטגוריה |
| subcategory | TEXT | תת-קטגוריה (אופציונלי) |
| description | TEXT | תיאור |
| image_url | TEXT | נתיב לתמונה שהועלתה |
| rental_price_per_day | REAL | מחיר השכרה ליום (₪) |
| overdue_price_per_day | REAL | קנס איחור ליום (₪) |

### טבלת `loans`
| עמודה | סוג | תיאור |
|-------|-----|--------|
| id | INTEGER | מזהה ייחודי |
| equipment_id | INTEGER | מזהה הציוד |
| borrower_name | TEXT | שם השואל/שוכר |
| borrower_phone | TEXT | טלפון |
| loan_date | TEXT | תאריך התחלה |
| expected_return | TEXT | תאריך החזרה המתוכנן |
| actual_return | TEXT | תאריך החזרה בפועל (null = עדיין מושאל) |
| notes | TEXT | הערות |
| loan_type | TEXT | סוג: `loan` (השאלה) / `rental` (השכרה) |
| price_per_day | REAL | מחיר ליום שנשמר בעת יצירת ההשאלה |
| card_last4 | TEXT | 4 ספרות אחרונות של כרטיס האשראי |
| card_expiry | TEXT | תוקף הכרטיס |
| card_holder | TEXT | שם בעל הכרטיס |
| payment_status | TEXT | סטטוס תשלום: `pending` / `charged` / `none` |

### טבלת `categories`
| עמודה | סוג | תיאור |
|-------|-----|--------|
| id | INTEGER | מזהה ייחודי |
| name | TEXT | שם הקטגוריה (ייחודי) |
| icon | TEXT | אמוג'י לייצוג הקטגוריה |

## 🔌 API Endpoints

### ציוד
| Method | Endpoint | תיאור |
|--------|----------|--------|
| GET | `/api/equipment` | כל הציוד |
| GET | `/api/equipment/:id` | פריט לפי ID |
| GET | `/api/equipment/new-barcode` | יצירת ברקוד ייחודי |
| GET | `/api/equipment/:id/barcode` | תמונת ברקוד PNG |
| GET | `/api/equipment/barcode/:barcode` | פריט לפי ברקוד |
| POST | `/api/equipment` | הוספת ציוד |
| PUT | `/api/equipment/:id` | עדכון ציוד |
| DELETE | `/api/equipment/:id` | מחיקת ציוד |
| GET | `/api/subcategories/:category` | תתי-קטגוריות לפי קטגוריה |
| POST | `/api/upload` | העלאת תמונה |

### השאלות
| Method | Endpoint | תיאור |
|--------|----------|--------|
| GET | `/api/loans` | כל ההשאלות |
| GET | `/api/loans/overdue` | השאלות באיחור |
| GET | `/api/loans/equipment/:id` | היסטוריה לפי ציוד |
| POST | `/api/loans` | יצירת השאלה/השכרה |
| PUT | `/api/loans/:id/return` | סימון כהוחזר (נחסם אם יש חיוב פתוח) |
| PUT | `/api/loans/:id/charge` | חיוב כרטיס אשראי |

### קטגוריות
| Method | Endpoint | תיאור |
|--------|----------|--------|
| GET | `/api/categories` | כל הקטגוריות |
| POST | `/api/categories` | הוספת קטגוריה |
| DELETE | `/api/categories/:id` | מחיקת קטגוריה |

## ✨ פיצ'רים

- 📦 תצוגה היררכית: קטגוריה ← תת-קטגוריה ← פריטים
- 🗂 תת-קטגוריות דינמיות — נוצרות אוטומטית מהפריטים, עם השלמה אוטומטית בטופס
- 🖼 העלאת תמונה לפריט (שמירה מקומית ב-`backend/uploads/`)
- 🖨️ הדפסת כל הברקודים לדף PDF מסודר (4 עמודות, A4)
- 🔢 ברקוד נוצר אוטומטית בהוספת פריט חדש (פורמט `SG-XXXXXXXX`)
- 🔖 ברקוד ייחודי לכל פריט + הדפסה בודדת מדף הפרטים
- 📷 סריקת ברקוד דרך מצלמת הדפדפן
- 📤 השאלה והחזרה של ציוד
- 💰 השכרת ציוד עם מחיר קבוע ליום (מוגדר בפרטי הציוד)
- 💳 תשלום מאובטח בכרטיס אשראי (אימות Luhn) לכל השאלה/השכרה
- ⚠️ חסימת החזרה עד לתשלום קנס איחור / דמי השכרה
- 🔄 אנימציית עיבוד תשלום — "מעביר לחברת האשראי..." ואישור חיוב
- ⚠️ לחיצה על "באיחור" מנווטת ישירות לרשימת האיחורים
- 📋 היסטוריית השאלות לכל פריט
- 🔍 חיפוש וסינון בתוך קטגוריה
- ⚙️ ניהול קטגוריות — הוספה ומחיקה עם בחירת אמוג'י

- חסימת החזרה אם יש חיוב פתוח — מוצג בלוק תשלום עם פירוט הסכום
- אנימציית עיבוד תשלום: ספינר + "מעביר לחברת האשראי..." ← "✅ חיוב בוצע בהצלחה!"
